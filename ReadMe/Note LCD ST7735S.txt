# LCD pinout setting and explain

    + CSX: Chip select enable - LCD can only be read or written when CSX is low enable, CSX = 1 : disable, CSX = 0 : enable. Signal trasition must be larger than 10ns

    + SCL: Write: 80ns, Read: 160ns.

    + D/CX: D/CX = 0 => command mode, D/CX = 1 => data mode. Signal trasition must be larger than 20ns

    + SDA: Write min: 20ns, Read min: 20ns.

    + RESX: Reset pulse duration: 10us. = 500 compare to 20ns.

    + LED: Always high.
